# Capstone Explorer listing
Implement visible_entries(paths, show_hidden=False) in explorer.py.
Return a new list of the original path strings, sorted case-insensitively by basename.
Exclude any entry whose basename starts with a dot unless show_hidden=True.
Do not change the input sequence. Accept an empty sequence.
When basenames compare equally, retain their original relative order.
Only use Python standard library. Do not publish or alter this specification.
